# Latency experiment: the replies, blind (2026-11-11)

Each letter is one model at one thinking setting. Which is which is in the key file beside this one; read this first.

How to read it:

- Every lettered reply to a turn answers the same player line with the same story behind it (the same saved campaign state, the same last twenty rows, the same memory). The only difference between letters is the model and the setting.
- "The story so far" is the reply the recording run gave. The story moves on from that reply, not from any lettered one, so a lettered reply that sends the scene somewhere else is not carried into the next turn.
- The text is what the player sees: the trailing event block is cut, as the game cuts it.
- The letters appear in a different order on each turn. 6 letters, 20 ordinary turns, then one skill check and one fight round each.
- A verdict per letter is what the decision needs: which letters, if any, read worse than the others, and whether any difference would matter in play.
